#### NeuroSilent AI 🧠🎙️

An AI-powered web platform built to help people speak again when the nervous system signals between their brain and vocal cords are disconnected. By combining a non-invasive headband and a neck-wear sensor with an AI agent, **NeuroSilent AI** reads early brain and throat signals and turns them into real-time text and natural speech. 

**Backstory:** I first came up with this idea and designed the core concept during the **New York Academy of Sciences (NYAS)** program this fall. Now, I'm building out the web platform and software side to bring it to life. 

#### 💡 Why I'm Building This

A lot of people lose their ability to speak due to nerve damage, trauma, or neurological conditions—even though their brain is completely active and they still have so much they want to say. Right now, most assistive tools (like eye-tracking boards) feel clunky, slow, and exhausting to use in a normal conversation. 

I wanted to create something faster and way more natural. **NeuroSilent AI** catches speech intent straight from the brain and throat before those signals get lost, giving people a real-time voice again. 

#### ⚙️ How It Works

1. **The Wearables (Signal Capture):** 

  * **Headband:** Uses non-invasive EEG sensors to pick up brain activity when a person thinks about speaking.
  * **Neck-Wear:** Picks up tiny muscle impulses and micro-vibrations around the throat and vocal tract.
2. **The AI Agent (Decoding):** 

  * Cleans up background noise and combines the data from both the headband and neck sensor.
  * Uses machine learning to figure out the intended words, phrases, and context.
3. **The Web Platform (Real-Time Output):** 

  * Shows the decoded words live on a clean web dashboard.
  * Turns that text into natural-sounding audio so the user can actually talk in real-time conversations.

#### ✨ Main Features (Planned & In-Progress)

* **Dual-Sensor Sync:** Combines brainwaves (headband) with throat signals (neck-wear) so the AI makes way fewer mistakes.
* **Personalized AI:** Adapts to each user's unique brain patterns and speaking style the more they use it.
* **Live Web Dashboard:** A simple, accessible interface for reading live transcriptions, checking chat history, and calibrating the sensors.
* **Natural Voice Output:** Converts decoded thoughts into clear, human-like speech instead of a robotic voice.
